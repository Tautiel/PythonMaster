## 🎯 TRAPPOLE CRITICHE DA MEMORIZZARE

### Le 15 Trappole dell'Esame PCEP

```python
# 1. PRECEDENZA OPERATORI LOGICI: not > and > or
print(True or False and False)  # True (and prima!)

# 2. and/or RESTITUISCONO VALORI, non bool
print(5 and 3)   # 3
print(0 or 3)    # 3

# 3. DIVISIONE: / sempre float, // floor
print(5 / 2)     # 2.5
print(5 // 2)    # 2

# 4. FLOOR CON NEGATIVI: verso -infinito
print(-7 // 2)   # -4 (NON -3!)

# 5. MODULO: segno del divisore
print(-7 % 2)    # 1 (NON -1!)

# 6. ESPONENTE: associa a DESTRA, precedenza su unario
print(2 ** 3 ** 2)  # 512 (2^9)
print(-3 ** 2)      # -9 (NON 9!)

# 7. else NEI LOOP: eseguito se NO break
for i in range(3):
    pass
else:
    print("done")  # Eseguito!

# 8. RIFERIMENTI vs COPIE
a = [1, 2]
b = a       # Riferimento!
b = a[:]    # Copia!

# 9. += vs + PER LISTE
a = [1]; b = a
a += [2]    # Modifica in place, b cambia!
a = a + [3] # Nuova lista, b non cambia!

# 10. DEFAULT MUTABILE
def f(lst=[]):
    lst.append(1)  # TRAPPOLA! Lista condivisa!

# 11. UnboundLocalError
x = 10
def f():
    print(x)  # ERRORE se sotto c'è x = 20!
    x = 20

# 12. (1) vs (1,) - int vs tuple!
print(type((1)))   # int
print(type((1,)))  # tuple

# 13. in NEI DICT: verifica CHIAVI
d = {"a": 1}
print(1 in d)   # False (1 è valore!)

# 14. CHIAVI DUPLICATE: ultima vince
d = {"a": 1, "a": 2}
print(d["a"])  # 2

# 15. finally SOVRASCRIVE return
def f():
    try: return 1
    finally: return 2
print(f())  # 2
```
